# LUCENT PSC — Combined Website

This combined static website retains the original `lucent_psc_website.html` design, Malayalam typography, cyan/amber colour palette, course cards, original quiz, testimonials and contact layout. It adds learning and media features from the supplied `lucent-psc-github.zip`.

## Included files
- `index.html` — GitHub Pages entry point.
- `assets/lucent-psc-logo.png` — supplied Lucent PSC logo.
- `assets/study-hero.png` — supplied learning banner.
- `.nojekyll` — GitHub Pages helper.

## Combined features
- Original design, courses, testimonials and Malayalam quiz.
- Learning toolkit and four-step study routine.
- Four supplied YouTube video IDs, thumbnails, captions and click-to-play embeds.
- YouTube channel, video and live-session links.
- Instagram and Threads links.
- Malayalam motivational quote with supplied logo and banner images.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Extract this ZIP.
3. Upload the contents of the extracted folder (not the enclosing folder) to the repository root.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish and show the website URL.

## Before public launch
- Replace the contact address, phone number and email placeholders with verified official details.
- Verify the source template's claims and figures (including “No. 1”, 5000+ winners and 15+ teachers) before publishing them as facts.
- Verify course names, schedules, fees and admission information.
- The enquiry form is front-end only. It does not transmit or store enquiries. Connect a form backend/service before inviting real submissions.
- Review the original quiz answers and video titles/durations before using them for exam preparation.
- Tailwind CSS, Font Awesome, Google Fonts, YouTube thumbnails and embedded videos use external services and require internet access.

This is a static website package; no backend or form-submission service is included.
